# 可选排法：审核偏好 v1

默认排法仍是时间重置法（`FingeringStyle.TimeReset`）。审核偏好（`ReviewPreferenceV1`）是另一种可选排法，需要玩家在排键设置中主动选择；切回时间重置法即可恢复原排法。它不按曲名、砖号或谱面位置设置特例。

## 适用范围

两种排法共用当前上游的转角判多押、三押/四押、长按和多押用手逻辑。审核偏好只对不含长按的谱面调整单押手序，不改变分组、音符时刻、砖块范围或长按时值；含长按时整谱沿用时间重置法。

- **多押附近让手**：有效范围取 `min(ChordFocusWindow, ResetWindow)`。默认不超过 165 ms，离开这个范围后使用正常起手逻辑。
- **中速单押片段**：由多押或大于重置间隔的空隙分开。片段内部每个间隔均大于 `ResetWindow / 2`、不超过 `ResetWindow` 时，尝试左右食指交替。
- **等速短串**：只在允许轮指且使用外轮时考虑。连续单押数量、间隔和均匀度满足下表时，尝试左右食指交替；实际最大间隔还受 `ResetWindow / 2` 限制。
- **整段衔接**：先尝试主手起手，再尝试另一相位；前后相邻音符的连按或外轮方向检查不通过时保留原排法。最终仍统一执行惯用手镜像。

## 短串参数

参数使用有名称的 `FingeringOptions` 属性，并随审核导出记录，便于重跑同一组配置。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `ReviewShortMinGap` | 0.060 s | 短串每步最小间隔 |
| `ReviewShortMaxGap` | 0.0825 s | 短串每步最大间隔，还需不超过重置间隔的一半 |
| `ReviewShortMinNotes` | 4 | 最短音符数 |
| `ReviewShortMaxNotes` | 5 | 最长音符数 |
| `ReviewTimingTolerance` | 0.001 s | 片段最大、最小间隔之差上限 |

46.875 ms 的极快片段和 6 音以上的持续轮指不属于默认短串范围。内轮、关闭轮指、左右惯用手及多押用手选项继续遵从各自设置。

这些阈值是可测试的候选范围，不能视为每位玩家的精确手速边界。尚无长按样本支持对长按占手重新分配，因此没有把短串规则扩展到长按谱。

## 审核与验证

游戏里选好排法后，从 Mod 设置的「状态」页导出当前关卡，使用本地编辑器记录实际改键和理由。游戏导出保留实际 `TileHit.Angle`、时序、全部排键参数和算法标识，是正式审核的依据。网页直接打开原谱使用离线近似时序。

开发时可用 `tools/Preview.cs --review-rules --review-export 输出.review.json` 选择此排法并导出；不加 `--review-rules` 时仍是时间重置法。C# 回归测试检查参数边界、镜像、多押用手、长按回退及结构不变；JavaScript 排键与 C# 使用自动生成的合成基线逐项对照。

旧 PR 曾对三份只含时间、不含转角的审核快照进行统计。那属于旧时间判双押算法的历史实验，不能用来证明当前转角判多押、三押/四押实现的命中率，也不能把未修改位置视为用户认可。当前规则需要在带转角的新游戏导出上继续审核。
