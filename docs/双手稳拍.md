# 双手稳拍

此分支以正式发布的 RhythmHint 1.3.5 为基础。在游戏中打开 F8 → 排键 → 排法 → 双手稳拍。手序编辑器的参考面板可以显示并应用这套手序。已有设置继续控制惯用手、轮指和多押用手。

## 排键规则

- 先用拍位、相邻节奏和入砖方向选择左右手。快速等距的单双押混排把每个双押当成一个节奏位置，整体交替。极快短轮指根据接拍选择收尾，持续快串使用四指循环。
- 慢速重复图形中，若以主手带入且已有至少三分之二的音在同一只手上，优先把零星换手并回主手。
- 加速的衔接段让主手先打完较宽的接拍，进入密集分拍后再交替。已有交替起手的三连音延续交替到尾音，下一拍再接回起手。
- 谱面原生的多次按键砖按游戏设置保留所需按键数。用多个普通砖写出的疑似多押只有两砖时才归为双押，三个以上的普通砖保留各自时刻。

## 1.3.5 兼容回放

从正式版 Release 下载 DLL，并用同一份六谱击打时间、审核拍线和游戏轨迹，对比正式版、此前安装的测试版和此分支构建。以击打时刻的首尾砖、时间、键位及长按时长逐项比较。

| 排法 | 与审核稿逐键一致 |
| --- | ---: |
| 1.3.5 正式版标准 | 6,495 / 9,613 |
| 1.3.5 正式版交替优先 | 7,479 / 9,613 |
| 原测试版双手稳拍 | 9,587 / 9,613 |
| 此分支双手稳拍 | 9,587 / 9,613 |

两套双手稳拍输出逐音一致。用会话的速度变化重新推算拍线，两套实现依然逐音一致。此分支内的标准与交替优先分别与正式版相同。
