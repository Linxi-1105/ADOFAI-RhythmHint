完成修改后导出 .review.json，保留原始排键、你的修改和理由；下次打开该 JSON 继续审核。重新打开原始 .adofai 会重新生成自动排键，不会将审核修改写回关卡。浏览器草稿仅保存在本机，请及时导出备份。
